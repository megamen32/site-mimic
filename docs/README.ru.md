# site-mimic (кратко по-русски)

Заставляет Go HTTP-клиент выглядеть на уровне транспорта как реальный
браузер, которого ждёт сайт: TLS ClientHello (форма JA3/JA4), ALPN,
HTTP/2 и захваченный набор заголовков.

- Библиотека `mimic` — uTLS (`chrome_auto` по умолчанию), h2 через ALPN с
  фолбэком на HTTP/1.1, поддержка CONNECT-прокси, самописец ClientHello.
- [`skill/SKILL.md`](../skill/SKILL.md) — последовательность «подогнать клиент
  под сайт» для ИИ-агентов: захват → профиль → проводка → проверка
  отпечатка → проверка бизнес-пути.
- Проверенные примеры: `examples/vk-ru` (200 по HTTP/2) и
  `examples/stream-wb-ru` (498-челлендж антибота `wbaas` ровно как у свежего
  реального браузера).

## Быстрый старт

```sh
git clone https://github.com/megamen32/site-mimic && cd site-mimic/examples/vk-ru
go run . -dump ch.json
python3 ../../tools/parse_clienthello.py ch.json
```

Зачем это нужно: стандартный Go-ClientHello однозначно отличим от
браузерного, и именно транспортный отпечаток первыми начинают резать
DPI-коробки (ТСПУ глушит по сигнатурам ClientHello/ServerHello — тот же
механизм, которым когда-то зарезали snowflake). Держать транспорт
браузеро-подобным — дешевле, чем потом чинить заблокированный клиент.

Честные ограничения (порядок заголовков на проводе, форма SETTINGS-фрейма
h2, JS-челленджи) — в [docs/methodology.md](methodology.md).
